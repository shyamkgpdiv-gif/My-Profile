What made me start coding?

The main reason which compelled to code was not clearly defined and not even i knew at that time that i would take coding seriously. It all started during the time when my summer vacations were about to end, i realised that I had wasted the entire summer vacation having fun and wasting my time. This regret of me made me think about doing something productive and useful in the remaining time of my summer vacation. I already knew some HTML from school so i decided to learn it from the internet. I went to youtube and searched for HTM tutorial and decided to start learning it. I learnt and made my first website using HTML and CSS and published it using github pages. From that moment I decided to take coding more seriously. So what made me start coding was the regret of wasting time.


What was my learning approach?

I started learning coding from Youtube. I found many amazing channels that taught programming concepts in a simple and easy-to-understand manner. One of my favorite channel is "Bro Code" who taught coding in a easy way while not making things too complex. I also used AI's like ChatGPT to ask doubts ,clarify concepts and take advices on future plans. I still use these resources to learn new things and improve my skills.


What languages have I learned?

The first language I learnt was HTML and CSS. After that i started learning python. Infact I started making this website after completing python fundamentals. Right now I want to master the main coding concepts so that when moving to another language ,the main transition problem I will face is learnig and adapting to the new syntax.
